# Nguồn Dữ liệu: Giám sát Chất lượng Không khí Hà Nội (2023)

## Tên Tệp
hanoi-aqi-weather-data.csv

## Mục đích
Dữ liệu được thu thập hàng giờ, sử dụng làm nguồn chính (Source Data) cho quy trình ETL, phục vụ cho việc phân tích xu hướng lịch sử và thiết lập cảnh báo sớm trong Kho Dữ liệu AirQuality_DW.

## Cấu trúc Dữ liệu (Các cột chính)
Dữ liệu ở dạng bảng rộng (Wide Format), chứa cả chỉ số không khí và thời tiết:

| Nhóm | Tên Cột | Mô tả |
|---|---|---|
| **Thời gian/Vị trí** | Local Time | Thời điểm đo (Dùng để tách DateKey và TimeKey). |
| | City, Country Code | Thông tin định danh vị trí (Dùng cho DimLocation). |
| **Chỉ số AQI** | AQI | Chỉ số Chất lượng Không khí (Air Quality Index). |
| | PM25, CO, NO2, O3, SO2 | Nồng độ các chất ô nhiễm. |
| **Chỉ số Thời tiết** | Temperature, Relative Humidity | Nhiệt độ, Độ ẩm. |
| | Wind Speed, Pressure, Clouds | Vận tốc gió, Áp suất, Mây. |
